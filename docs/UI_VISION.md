# PawQuest UI Vision

Этот документ фиксирует утверждённое визуальное направление приложения. Основа - одобренная демонстрационная компоновка с крупными карточками, мягкой пастельной палитрой, дружелюбной мобильной иерархией и акцентом на персонаже собаки.

## Главные принципы

- интерфейс должен выглядеть как polished mobile game, а не как утилитарный трекер;
- почти каждый главный экран имеет сильный визуальный центр: собака, карта, достижение, карточка породы, витрина магазина;
- использовать крупные скругления, мягкие тени, светлые карточки и тёплые акценты;
- визуальный приоритет у картинки и состояния собаки, затем у действия пользователя;
- навигация должна быть нижней, иконки + подписи, всегда стабильная;
- экраны должны быть понятны на телефоне без плотного текста;
- фото, спрайты и иллюстрации - обязательная часть UX, не второстепенное украшение.

## Основная навигация

- Дом
- Задания
- Карта
- Магазин
- Профиль

Дополнительные разделы: энциклопедия породы, здоровье, фото-дневник и достижения открываются из профиля и домашних карточек.

## Утверждённые экраны

### Welcome / onboarding
Крупная собака, выбор породы карточками с изображениями, отдельное поле клички, одна основная CTA-кнопка.

### Home
Собака является главным визуальным центром. Рядом показываются настроение, сытость, энергия, здоровье, быстрые действия и прогресс дня.

### Tasks
Вертикальный список реальных дел по уходу, XP и монеты за выполнение, дневной сундук за полный набор задач.

### Adventure map
Стилизованная игровая карта с домом, парком, лесом, пляжем и будущими локациями. Новые зоны открываются с уровнями.

### Shop
Большая витрина выбранного образа собаки и сетка костюмов. Косметика не меняет характеристики и существует как коллекционная мета-игра.

### Profile
Крупный портрет питомца, уровень, сведения о породе и входы в здоровье, фото-дневник, достижения и энциклопедию.

## Цвет и форма

- базовый фон: тёплый кремовый;
- основной акцент: бирюзово-голубой;
- награды: золотистый;
- дополнительные карточки: персиковый, бежевый, мягкий зелёный;
- крупные скругления и лёгкая объёмная тень;
- широкие CTA-кнопки с чёткой визуальной иерархией.

## Работа с артами

- собаки должны сохранять единый polished casual-mobile стиль;
- для каждой породы нужны портреты и полноценные sprite sheets;
- базовые состояния: idle, happy, walk, run, play, sit/lie, tired, sleep, celebrate;
- костюмы и аксессуары проектируются как отдельные overlay-слои;
- временные схематичные собаки не используются.

## Практическое правило

Каждый новый экран проверяется по вопросу: выглядит ли он как почти готовая мобильная игра из утверждённого визуального направления. Если нет, экран перерабатывается до этого уровня.
