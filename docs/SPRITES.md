# PawQuest sprite production brief

PawQuest использует полноценные растровые игровые иллюстрации. Схематичные заглушки не являются финальным визуалом.

## Первый набор пород

- такса (`dachshund`)
- джек-рассел-терьер (`jack-russell`)
- лабрадор-ретривер (`labrador`)

## Состояния персонажа

Для каждой породы нужен единый персонаж с одинаковой анатомией, масштабом и камерой во всех состояниях.

1. `idle` - 6 кадров
2. `happy` - 6 кадров
3. `walk` - 8 кадров
4. `play` - 8 кадров
5. `tired` - 6 кадров
6. `sleep` - 6 кадров
7. `celebrate` - 8 кадров

## Арт-дирекшн

- премиальная 2D game illustration;
- уютный, тактильный, слегка живописный рендер;
- хорошо читаемый силуэт на небольшом экране телефона;
- узнаваемые и правдоподобные пропорции конкретной породы;
- единый свет, ракурс и размер персонажа;
- прозрачный фон;
- никаких надписей внутри спрайтов;
- базовая собака рисуется без одежды;
- костюмы и аксессуары создаются отдельными выровненными слоями.

## Технический формат

- мастер-лист: 1024 x 1024 для каждого состояния;
- рабочие кадры: PNG или WebP с прозрачностью;
- JSON atlas для координат и длительности кадров;
- отдельные overlay-листы для одежды и аксессуаров;
- безопасная зона вокруг лап, хвоста и ушей, чтобы анимация не обрезалась.

## Структура файлов

```text
public/assets/sprites/<breed>/<state>/<frame>.webp
public/assets/sprites/<breed>/atlas.json
public/assets/cosmetics/<item>/<breed>/<state>/<frame>.webp
```

## Правила совместимости косметики

Каждый кадр косметики должен совпадать с базовым кадром по размеру холста и anchor point. Это позволит менять костюм без генерации новой копии всей собаки.

## Порядок производства

1. Утвердить character sheet каждой породы: вид спереди, 3/4 и сбоку.
2. Утвердить `idle` как эталон пропорций.
3. Сделать остальные состояния.
4. Нарезать кадры и собрать atlas.
5. Подключить state machine в приложении.
6. Только после этого производить большой набор косметики.
