# Мотя

Игровое веб-приложение о жизни с реальной таксой Мотей. Первая версия строится вокруг одной интерактивной комнаты: пользователь взаимодействует с Мотей и предметами в сцене, выполняет дела дня, получает косточки и монеты, а состояние сохраняется локально.

## Уже работает

- интерактивная домашняя сцена вместо дашборда;
- утверждённый игровой образ Моти, созданный по её реальным фотографиям;
- реакции на поглаживание, кормление, игру, прогулку и отдых;
- будний и выходной режимы дня;
- ежедневные задачи и награды;
- косточки, монеты и уровень связи;
- сохранение состояния в IndexedDB через Zustand;
- адаптивный интерфейс для телефона и desktop;
- GitHub Actions: typecheck, lint, tests, production build;
- workflow для публикации приложения через GitHub Pages.

## Образ Моти

- `public/assets/motya/motya-character-sheet.jpg` - утверждённый визуальный эталон персонажа;
- `public/assets/motya/motya-game.webp` - оптимизированный игровой ассет, который сейчас используется в домашней сцене.

В образе сохранены характерные особенности Моти: рыже-коричневый окрас, белая грудка, лёгкая седина у носа, загнутые кончики ушей, более длинные лапы и немного кривая передняя лапка.

## Запуск локально

```bash
npm install
npm run dev
```

Проверка перед коммитом:

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

## Структура

- `src/game` - состояние игры и IndexedDB persistence;
- `src/scenes` - игровые сцены;
- `src/components` - HUD и интерфейс поверх сцены;
- `public/assets/motya` - ассеты персонажа;
- `public/assets/rooms` - визуальные материалы локаций;
- `.github/workflows` - CI и GitHub Pages deployment.

## GitHub Pages

Проект настроен для публикации по адресу:

`https://smirnovairina7090-blip.github.io/dachshund/`

Если Pages включается для репозитория впервые, в GitHub нужно один раз открыть `Settings → Pages` и выбрать `Source → GitHub Actions`. После этого workflow `Deploy GitHub Pages` публикует `dist` при изменениях в `main`.
