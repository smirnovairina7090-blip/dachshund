# Мотя / PawQuest

Игровое приложение о жизни с реальной собакой. Текущая версия выросла из истории таксы Моти и теперь становится основой PawQuest: уход за реальной собакой превращается в игровую прогрессию с заданиями, состояниями питомца, наградами, коллекциями и знаниями о породе.

## Уже работает

- интерактивная домашняя сцена вместо дашборда;
- утверждённый игровой образ Моти, созданный по её реальным фотографиям;
- реакции на поглаживание, кормление, игру, прогулку и отдых;
- ежедневные задачи и награды;
- косточки, XP, уровень связи и серия дней;
- достижения, мини-игры и коллекция аксессуаров;
- локальное сохранение состояния;
- адаптивный интерфейс для телефона и desktop;
- GitHub Actions: typecheck, lint, tests, production build;
- GitHub Pages deployment;
- автоматическая сборка устанавливаемого Android APK через Capacitor.

## Образ Моти

- `public/assets/motya/motya-character-sheet.jpg` - утверждённый визуальный эталон персонажа;
- `public/assets/motya/motya-game.webp` - оптимизированный игровой ассет, который используется в домашней сцене.

В образе сохранены характерные особенности Моти: рыже-коричневый окрас, белая грудка, лёгкая седина у носа, загнутые кончики ушей, более длинные лапы и немного кривая передняя лапка.


```bash

npm run lint
npm test

```

## Android APK

Приложение упаковывается в Android через Capacitor. Нативная папка `android/` генерируется автоматически и не хранится в репозитории.

Для локальной подготовки:

```bash
npm install
npm run build:android:web
npx cap add android
npx cap sync android
```

После этого Android-проект можно открыть командой:

```bash
npm run android:open
```

### Автоматическая сборка в GitHub

Workflow `.github/workflows/android-apk.yml` собирает debug APK при изменениях в `main`, в рабочей ветке `agent/pawquest-foundation` и при ручном запуске.

Готовый файл появляется в артефактах workflow под именем `pawquest-android-debug`. Внутри находится `app-debug.apk`, который можно скачать на Android-телефон и установить после разрешения установки приложений из браузера или файлового менеджера.

## Структура

- `src/App.tsx` - текущий основной игровой интерфейс;
- `src/game` - ранняя модульная версия состояния игры и persistence;
- `src/scenes` - игровые сцены;
- `src/components` - HUD и интерфейс поверх сцены;
- `public/assets/motya` - ассеты персонажа;
- `public/assets/rooms` - визуальные материалы локаций;
- `capacitor.config.ts` - конфигурация мобильной оболочки;
- `.github/workflows/android-apk.yml` - сборка Android APK;
- `.github/workflows` - CI и GitHub Pages deployment.

## Направление PawQuest

Следующие продуктовые слои:

1. Онбординг: кличка, порода и выбор игрового образа собаки.
2. Первые породы: такса, джек-рассел-терьер и лабрадор-ретривер.
3. Отдельные состояния персонажа: idle, happy, excited, play, walk, tired, sleep и celebrate.
4. Породные базы знаний и рекомендации по уходу.
5. Более глубокая экономика: монеты, косточки, редкости, сундуки, сезонные коллекции и костюмы.
6. Реальный уход: прогулки, кормление, груминг, лекарства, вес, профилактика и календарь.
7. Уведомления и локальные напоминания на Android/iOS.

Спрайты и одежда должны оставаться раздельными слоями, чтобы один и тот же персонаж мог менять состояние и экипировку без дублирования всей графики.
