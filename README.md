# Мотя

Игровое веб-приложение о жизни с реальной таксой Мотей. Первая версия строится вокруг одной интерактивной комнаты: пользователь взаимодействует с Мотей и предметами в сцене, выполняет дела дня, получает косточки и монеты, а состояние сохраняется локально.

## Уже работает

- интерактивная домашняя сцена вместо дашборда;
- реакции на поглаживание, кормление, игру, прогулку и отдых;
- будний и выходной режимы дня;
- ежедневные задачи и награды;
- косточки, монеты и уровень связи;
- сохранение состояния в IndexedDB через Zustand;
- адаптивный интерфейс для телефона и desktop;
- GitHub Actions: typecheck, lint, tests, production build.

## Важно про образ Моти

`public/assets/motya/dev-motya.svg` - только технический черновой персонаж для проверки механики и композиции. Он должен быть заменён на согласованный игровой образ, созданный по реальным фотографиям Моти. Архитектура сцены уже отделяет персонажа от игровой логики, поэтому замена ассета не потребует переписывать механику.

## Запуск

```bash
npm install
npm run dev
```

Проверка перед коммитом:

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

## Структура

- `src/game` - состояние игры и IndexedDB persistence;
- `src/scenes` - игровые сцены;
- `src/components` - HUD и интерфейс поверх сцены;
- `public/assets/motya` - состояния персонажа;
- `public/assets/rooms` - визуальные материалы локаций;
- `.github/workflows` - CI.
