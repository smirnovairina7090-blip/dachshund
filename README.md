# Dachshund cozy room

Mobile-first interactive room prototype for the dachshund care game.

## Gestures
- Swipe empty space to pan through the room with inertia.
- Tap and drag furniture to rearrange it.
- Furniture scales subtly with floor depth to create a 2.5D effect.
- The layout is saved in localStorage.
- Ambient light, floating dust, plant movement and fireplace warmth make the room feel alive.
